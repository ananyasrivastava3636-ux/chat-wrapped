How do I export a WhatsApp chat?

Android: open the group → ⋮ menu → More → Export chat → Without media.

iPhone: open the group → tap the group name → Export Chat → Without Media.

Save the .txt file (unzip it first if it arrives as a .zip), then upload it here.
